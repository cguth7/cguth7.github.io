The Reality style guide.

Paper surface, serif display, monospace everything else, one deep green. Borrowed from the parse.bot marketplace language and tailored to a city's events. Every component on this page ships from reality.css — pages compose these, they don't invent new ones.

Principles

1. The UI is an honesty surface. Health, freshness, and provenance are always visible ("verified 2d ago", "5/5 checks", self-repair entries in history). Never claim more than the pipeline did.
2. Serif speaks, mono works. Newsreader for page titles and section headings only (h1, h2, card names). Everything else — body, labels, data — is mono.
3. One green. Accent, links, CTAs, tint fills all derive from --green. Status colors (amber, rust) appear only with an icon + word, never color alone.
4. Uppercase micro-labels (.kicker, .seclabel, .flabel, .lbl) do the wayfinding; headings stay sentence-case serif.

Map

Neighborhood polygons as inline SVG in a .mapcard — never map tiles. Fill classes .t1/.t2/.t3 deepen with event count; .sel on selection; .mk numbered markers match list ranks. Always a .legend. (Live example: today.html.)

Voice: sentence-case serif headings ("What is this source?", "The map"), mono micro-labels in caps, honest counts everywhere ("top 12 of 42"), and one footer line: what's illustrative, what schema shapes it. Footer signs off: Reality — make real life easier than the feed.
