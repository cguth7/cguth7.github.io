The gate — why “built” means something

How a source gets built

Built is a claim the pipeline has to earn — and keep earning. Four hands touch every source, in order:

  • Lead — the venue or organizer is filed, with where it was discovered attached
  • Scout — go/no-go triage: where events actually post, which adapter fits
  • Build gate — the adapter must return real normalized events before status flips to built
  • Steward — re-probes every built source; failures downgrade in public, never silently
