What is this source?

Do312 is Chicago's largest independent event aggregator. This pipeline pulls its full listing feed nightly, resolves each event to a venue and organizer, and emits the engine's normalized shape — the norm() contract every source shares. Because it's an aggregator, it is one source row that feeds many venues: coverage links are connected as new venues appear in the feed, never duplicated per venue. Events it lands are scored by the Rater on the five universal dimensions; scores are appended, never overwritten.
